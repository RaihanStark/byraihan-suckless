      <h2>Introduction</h2>
      <p>
        A React Web Application built for showing Movies &amp; TV Series with The Movie Database API (TMDB). I created this in one-two days as a test for joining a company. It's pretty decent, so I showcased this on my portfolio.
      </p>

      <h2>Project Context</h2>
      <p>
        This project was developed as a technical assessment for a job application. Despite the tight timeline of just 1-2 days, I managed to create a fully functional movie catalog application that impressed the reviewers. The rapid development showcased my ability to:
      </p>
      <ul>
        <li>Work efficiently under time constraints</li>
        <li>Quickly integrate third-party APIs</li>
        <li>Build a polished UI with Material Design</li>
        <li>Implement modern React patterns</li>
      </ul>

      <h2>Key Features</h2>

      <h3>Movie &amp; TV Browsing</h3>
      <ul>
        <li><strong>Trending Content</strong>: Display trending movies and TV shows</li>
        <li><strong>Popular Lists</strong>: Browse popular content across categories</li>
        <li><strong>Search Functionality</strong>: Search for any movie or TV series</li>
        <li><strong>Detailed Information</strong>: View comprehensive details for each title</li>
      </ul>

      <h3>Content Details</h3>
      <ul>
        <li>Movie/TV show synopsis and overview</li>
        <li>Cast and crew information</li>
        <li>User ratings and reviews</li>
        <li>Release dates and runtime</li>
      </ul>

      <h3>User Interface</h3>
      <ul>
        <li>Clean Material Design interface</li>
        <li>Responsive grid layout</li>
        <li>Smooth transitions and animations</li>
        <li>Dark mode support</li>
        <li>Mobile-optimized experience</li>
      </ul>

      <h3>Technical Features</h3>
      <ul>
        <li>Efficient API data fetching</li>
        <li>Image lazy loading</li>
        <li>State management with React Context</li>
        <li>Error handling and loading states</li>
        <li>SEO-friendly routing</li>
      </ul>

      <h2>Technology Stack</h2>

      <h3>Core Technologies</h3>
      <ul>
        <li><strong>JavaScript</strong> - Programming language</li>
        <li><strong>React JS</strong> - UI library for component-based architecture</li>
        <li><strong>React Context</strong> - State management solution</li>
      </ul>

      <h3>UI &amp; Styling</h3>
      <ul>
        <li><strong>Material UI</strong> - Component library for consistent design</li>
        <li><strong>CSS-in-JS</strong> - Styled components for dynamic styling</li>
      </ul>

      <h3>Data &amp; Deployment</h3>
      <ul>
        <li><strong>Axios</strong> - HTTP client for API requests</li>
        <li><strong>TMDB API</strong> - The Movie Database free API</li>
        <li><strong>Vercel</strong> - Deployment and hosting platform</li>
      </ul>
